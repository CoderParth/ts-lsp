
A LSP written from scratch in TypeScript. No AI, No Vibe Coding -- done completely for my learning purposes. 

Although, it does not do anything specific for any language, for learning I made the client (in this case Neovim)
start it for .txt files. It provides various lsp features such as hover, code action, completion, and diagnostics.
